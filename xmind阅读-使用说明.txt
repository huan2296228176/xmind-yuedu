【一、一句话总结】

给你做了一个能打开、看、改、存 .xmind 思维导图文件的网页，
不用装任何软件，手机电脑都能用，断网也能用。
已经发布到网上了，手机上加到主屏幕后就跟个 App 一样。


【二、电脑里多了哪几个文件？都在哪？】

位置：d:\软件\xmind阅读\ 这个文件夹，一共 5 个文件：

1. index.html
   最主要的一个，整个网页就靠它。界面、样式、功能代码全在里面。
   以后想改功能、改样子，基本都是改它。

2. jszip.min.js
   一个别人写好的"压缩包工具"。因为 .xmind 文件其实就是个压缩包，
   靠它来解包和重新打包。已经下载到本地，断网也能用。

3. manifest.webmanifest
   相当于这个"App 的名片"：叫什么名字、用什么图标、
   打开后是不是全屏。手机加到主屏幕时靠它。

4. sw.js
   "离线小仓库"。第一次打开网页后，它把所有文件偷偷存一份，
   以后断网也能打开。

5. icon.svg
   App 图标，一个蓝色底、画着思维导图的图案。


【三、这个网页是怎么干活的？（原理，听个大概就行）】

1. 打开文件
   .xmind 文件本质是个压缩包。点"打开文件"选中后，
   先用 jszip 解包，里面有两种可能的"目录文件"：
   新版 XMind（2020以后）叫 content.json，老版（XMind 8）叫 content.xml。
   程序先找新的，找不到再找老的，读出来变成一张"节点树"。

2. 显示
   把节点树一层一层画成带缩进的大纲，就像文件夹列表。
   点小箭头能展开、收起；顶栏按钮能一键全展开/全收起。

3. 编辑
   点文字就能改名字（回车确认，Esc 取消）；
   每行右边有三个小按钮：＋子（加下级）、＋兄（加同级）、删（删除）。

4. 导出
   点"导出"，把改好的树再变回 content.json，
   用 jszip 打包成一个新的 .xmind 下载到手机/电脑。
   原文件完全不动，导出的叫"原名-编辑.xmind"。


【四、后来修了哪些毛病？（第二遍改动的）】

1. 展开收起的小箭头在部分安卓手机上是"方框乱码"
   原因：那些手机缺这个字符的字体。
   解决：不用字符了，改用代码画的箭头，什么手机都不会乱码。

2. 中文字体在一些设备上显示不好看
   解决：把常见的中文字体都列进了备选名单，哪家在就用哪家。

3. 苹果手机上点编辑框，页面会突然放大
   解决：编辑框字号提到 16px（苹果的规矩：小于16就放大页面）。

4. 苹果手机上选不了 .xmind 文件（文件是灰的）
   原因：苹果不认识 .xmind 这个后缀。
   解决：苹果手机上取消文件类型限制，打开时再检查。

5. 编辑完字，紧接着点别的按钮要点两次才有反应
   原因：改完字整个页面重画了一遍，把你的点击"吞"了。
   解决：改完字只更新那一小行，不重画整页。

6. 以后改了代码，老用户怎么知道要更新？
   sw.js 里有个版本号（现在是 v2），大改动后把它改成 v3、v4……
   用户刷新一下就自动换新版。


【五、怎么发到网上的？（部署过程回顾）】

1. 在 d:\软件\xmind阅读\ 文件夹里初始化了 git（本地版本记录），
   并把 5 个文件提交存档。

2. 你用自己的账号 huan2296228176 在 GitHub 网页上
   建了个叫 xmind-yuedu 的公开仓库。

3. 把代码推送（上传）到 GitHub。
   中间有个小插曲：第一次上传时网络抽风连不上，重试一次就成功了；
   上传时弹过一次"授权"窗口，点过 Authorize 后已经记住，
   以后上传不会再弹。

4. 在 GitHub 仓库的 Settings → Pages 里，
   把发布来源设成 main 分支，等了一两分钟就上线了。

【六、以后自己想改，看这张对照表】

想改什么            去哪里改
----------------    ------------------------------------------------
页面上的文字、按钮  index.html 搜对应的字
颜色、间距、字体    index.html 开头 <style> 部分
功能逻辑            index.html 下面 <script> 部分
App 名字/图标       manifest.webmanifest 和 icon.svg
离线缓存            sw.js（改动大记得把 v2 改成 v3）

两个红线，别碰：
1. index.html 里那个叫 esc 的"安检函数"，节点文字显示前必须过它，
   去掉了网页会被人塞恶意代码（安全漏洞）。
2. 编辑框的字号别低于 16px，不然苹果手机一点编辑就放大页面。

另外：新加文件后记得 git add 时把它加进去，
不然线上不会有这个文件。


【七、常用命令速查（在 d:\软件\xmind阅读 里运行）】

改完代码想更新到网上，三条命令：

    git add .
    git commit -m "update"
    git push

大约 1 分钟后线上自动更新。
不确定有没有更新成功：打开网址按 Ctrl+F5 强制刷新看效果。


【八、出问题了怎么查？】

1. 线上打不开 → 等一两分钟再刷（GitHub 发布有延迟）
2. 改了代码线上没变化 → 检查有没有 push；再把 sw.js 版本号 +1
3. 手机上界面旧了 → 强制刷新一次，或重新添加到主屏幕
4. 打开 .xmind 报错 → 确认是正常的 .xmind 文件（新版老版都支持）
